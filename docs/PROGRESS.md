## Conventions
- Sidebar: `config/admin_menu.php` (`route` or `'soon' => phase`); permissions: `config/admin_permissions.php` (+ `PermissionSeeder`); super admin = users.type `admin` (Gate::before).
- Settings: `get_setting()` / `setting_on()`; save via POST `admin/business-settings/update` with `types[]`; secrets via `admin/env-key-update` (`config/admin_env_keys.php`).
- Helpers: `cleanBdPhone()`, `format_price()` (৳), `format_date()` (d-m-Y h:i A, Asia/Dhaka), `uploaded_asset()`.
- Media: `<x-upload-field>` + global picker; uploads converted to webp (`UploadService`).
- UI: Blade + Tailwind 4 (`@utility` classes in `resources/css/app.css`) + Alpine (`resources/js/*.js`); `<x-switch>` posts to `admin/toggle/{resource}/{id}`; deletes via `confirmDelete(url)`.
- Translations: `backend/lang/bn.json`.
- Tests: `php artisan test` (sqlite memory). Build: `npm run build`.
